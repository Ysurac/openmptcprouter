MPTCP & BONDING SETTINGS (kernel parameters)
─────────────────────────────────────────────────────────────────────────────────
Enable MPTCP:              net.mptcp.enabled = 1
Congestion Control:        net.ipv4.tcp_congestion_control = bbr
Buffer Sizes:              net.core.rmem_max = 134217728 (128MB)
Connection Tracking:       net.netfilter.nf_conntrack_max = 524288
TCP Window Scaling:        net.ipv4.tcp_window_scaling = 1
SACK/DSACK:               net.ipv4.tcp_sack = 1
Multipath Hash Policy:     net.ipv4.fib_multipath_hash_policy = 1
RP Filter Mode:           net.ipv4.conf.all.rp_filter = 2 (loose)
IPv6 Forwarding:          net.ipv6.conf.all.forwarding = 1
IP Forwarding:            net.ipv4.ip_forward = 1

QUICK TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────────
Issue                          Command/Action
──────────────────────────────────────────────────────────────────────────────
Can't access web UI?           Run: omr-recovery
Check WAN status?              Run: omr-status
System health diagnostic?      Run: omr-diagnostics check
Emergency lockout?             Safety monitor auto-recovers in 60s
All ports on WAN?              Recovery → option 1 (restore LAN)
Wrong IP address?              Recovery → option 2 (reset to 192.168.2.1)
DHCP not working?              Recovery → option 3 (enable DHCP)
Factory reset?                 Recovery → option 4 (reset all)
