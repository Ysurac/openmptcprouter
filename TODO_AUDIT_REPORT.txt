3.1 CRITICAL SECURITY ISSUES (Must Fix Immediately)

Issue #1: XSS VULNERABILITY - Unsafe innerHTML Usage
  Location: common/package/luci-theme-omr-optimized/htdocs/luci-static/omr-optimized/js/theme.js:85
  Code: tooltip.innerHTML = `<div class="tooltip-inner">${tooltipText}</div>`;
  Problem: User-provided data directly inserted via innerHTML
  Impact: Remote code execution via malicious tooltip attribute
  Severity: CRITICAL
  Fix: Use tooltip.textContent = tooltipText; instead
  Status: NOT FIXED

Issue #2: CODE INJECTION - Dangerous Function Constructor
  Location: js/theme.js:304
  Code: el.addEventListener('scroll', new Function(scrollHandler), { passive: true });
  Problem: Creates functions from string attributes (scrollHandler)
  Impact: Arbitrary JavaScript execution if scrollHandler contains malicious code
  Severity: CRITICAL
  Fix: Never use new Function() with user input; refactor to use proper event handlers
  Status: NOT FIXED

Issue #3: ACCESSIBILITY VIOLATION - User Zoom Disabled
  Location: luasrc/view/themes/omr-optimized/header.htm:20
  Code: <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
  Problem: Prevents users from zooming; violates WCAG 2.1
  Impact: Visually impaired users cannot magnify content
  Severity: CRITICAL (WCAG compliance)
  Fix: Remove "maximum-scale=1.0" and "user-scalable=no"
  Status: NOT FIXED
