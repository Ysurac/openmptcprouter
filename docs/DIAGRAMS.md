## Device Nodes Reference

### USB Modem Device Nodes

```
/dev/
├── cdc-wdm0          # QMI/MBIM control channel
├── cdc-wdm1          # Secondary control (if present)
├── ttyUSB0           # AT command port
├── ttyUSB1           # NMEA GPS (if supported)
├── ttyUSB2           # Diagnostics/Debug
└── ttyUSB3           # Additional port

/sys/class/net/
└── wwan0             # Data interface (qmi_wwan or cdc_mbim)
```

### PCIe Modem Device Nodes

```
/dev/
├── wwan0at0          # AT command channel (MHI)
├── wwan0qmi0         # QMI control channel (MHI)
├── wwan0mbim0        # MBIM control channel (MHI)
└── wwan0diag0        # Diagnostics (MHI)

/sys/class/net/
├── wwan0             # Standard WWAN interface
└── mhi_hwip0         # High-performance MHI netdev

/sys/bus/mhi/devices/
└── 0000:01:00.0/
    ├── mhi_state     # M0 = normal operation
    └── power_state
```
